- **Education:** Modern vertical timeline covering Rajalakshmi Institute of Technology (B.Tech in Artificial Intelligence & Data Science).
- **13 Infosys Springboard Certifications:** Interactive grid with credential detail modals and search/filter capability.
- **Hackathons & Achievements:** Smart India Hackathon (SIH) and Designathon 2.0 participation details.
- **Currently Exploring Opportunities:** Dedicated fresher career section targeting internships, junior engineering roles, and technical collaborations.
- **Live GitHub Integration:** Synchronized with `github.com/santhoshkumarr376` using the GitHub REST API with offline fallback.
- **Contact Form:** Interactive contact form with live validation, direct email routing, and confetti celebration on submit.
- **ATS Resume Modal:** Integrated interactive resume with 1-click **Print to PDF** and **Download PDF** actions.

## 💻 Quick Start & Local Development

1. Open a terminal in this directory:
   ```bash
   cd C:\Users\Admin\.gemini\antigravity\scratch\santhosh-portfolio
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

4. Preview the production build:
   ```bash
   npm run preview
   ```

## 🌐 1-Click Deployment to Vercel

This project is fully pre-configured for instant deployment on Vercel:

1. Push this repository to your GitHub account:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Santhosh Kumar R. Premium Portfolio"
   git branch -M main
   git remote add origin https://github.com/santhoshkumarr376/portfolio.git
   git push -u origin main
   ```
2. Log in to [vercel.com](https://vercel.com) and import the repository.
3. Framework Preset: **Vite**. Build Command: `npm run build`. Output Directory: `dist`.
4. Click **Deploy**. Your portfolio is live with a free custom SSL domain!
